# 🚀 Deploy Mobile App to Vercel — 5 Minutes

## You're 1 Click Away

The mobile app web version is **ready to deploy**. Here's the fastest way:

---

## Step 1: Go to Vercel

Open this link in your browser:  
**https://vercel.com/new**

---

## Step 2: Select Repository

1. Click **Continue with GitHub**
2. Select: **`paymax2022/spotlight-latest1`**

---

## Step 3: Configure Project

Fill in these fields (copy/paste below):

| Field | Value |
|-------|-------|
| **Project Name** | `spotlight-mobile` |
| **Framework** | Other |
| **Root Directory** | `mobile-app/reactnative` |
| **Build Command** | `npx expo export --platform web --output-dir dist` |
| **Output Directory** | `dist` |

## Step 4: Deploy

1. **Scroll down** (check if env vars needed)
2. **Click "Deploy"** button (green, bottom right)
3. ⏳ Wait 5-10 minutes

---

## Step 5: Verify

When you see the ✅ checkmark:
1. Click **"Visit"** button
2. Should see your Paymax mobile app in browser
3. Test navigation, responsiveness

**URL will be:** `https://spotlight-mobile.vercel.app`

## 🔧 If Build Fails

**Check:**
1. Vercel build logs (red ❌ shown in dashboard)
2. Common errors:
   - "Cannot find module" → Path issue (fixed ✅)
   - "Build timed out" → Try again
   - "No space left" → Vercel issue, contact support

**Fix:**
1. Fix locally
2. Push to GitHub
3. Redeploy from Vercel dashboard
