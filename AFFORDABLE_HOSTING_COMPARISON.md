## 🚀 Deploy to Railway in 5 Minutes

### Step 1: Create Account
```
https://railway.app
Click "GitHub Login" → Authorize
```

### Step 2: Create Project
```
1. Click "New Project"
2. Click "Deploy from GitHub"
3. Select: paymax2022/spotlight-latest1
```

### Step 3: Add Services

**Backend:**
```yaml
Service Type: Docker
Dockerfile: Dockerfile (root)
Port: 8091
Memory: 512MB
```

**Admin:**
```yaml
Service Type: Docker
Dockerfile: frontend-admin/Dockerfile
Port: 3001
Memory: 512MB
```

**Mobile:**
```yaml
Service Type: Docker
Dockerfile: mobile-app/reactnative/Dockerfile
Port: 8083
Memory: 512MB
```

**Database:**
```yaml
Service Type: PostgreSQL
(auto-configured, auto-backed up)
```

### Step 4: Set Environment Variables
```
DATABASE_URL=<auto-generated>
JWT_SECRET=your-secret
PAYSTACK_SECRET=your-secret
NEXT_PUBLIC_API_URL=https://backend-url/api/v1
```

### Step 5: Deploy
Click "Deploy" → Wait 10 minutes → Done! ✨

## 🥈 Alternative: Fly.io

### Why Fly?

✅ **Affordable:** $3-30/month  
✅ **Global:** Deploy to 30+ regions  
✅ **Fast:** Edge caching built-in  
✅ **Docker native:** Excellent support  
✅ **PostgreSQL support:** Built-in  

### Deploy to Fly

```bash
# 1. Install
curl -L https://fly.io/install.sh | sh

# 2. Login
flyctl auth login

# 3. Create app
flyctl launch

# 4. Deploy
flyctl deploy

# 5. Get URL
flyctl info
```

### Cost
- Backend: $3-5/mo
- Admin: $3-5/mo
- Mobile: $3/mo
- Database: $15/mo (shared PostgreSQL)
