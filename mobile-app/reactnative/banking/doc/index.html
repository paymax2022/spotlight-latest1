01. Environment Setup

This is React Native app, solution for easy development and management of your React Native app. 

You will need to setup your computer to prepare for configuring the Apitex React Native App.

  1. Install Node
  2. Install Visual Studio Code (Will use it for text editing and terminal - You can use any text editor and terminal/cmd)
  3. Install React Native (Installation React Native CLI)

To verify your installation run:

  1. node --version
  2. npm --version
  3. npm view react-native version
Setting up the development environment IOS & Android
https://reactnative.dev/docs/environment-setup

02. Run App

This is React Native project, and depends on node modules that need to be installed. Try using these commands to install modules.

  1. $ npm install
  2. $ npm install --legacy-peer-deps

This will install all required node modules. It can take some time. If you see some warning this is not a big issue. Even if you see red error messages try to run the project.

In your project run:

  1. cd ios
  2. pod install
  3. cd ..
  4. npx react-native-asset

Once node modules are installed, you can run the app.

  1. $ npm react-native run-android
  2. $ npm react-native run-ios
